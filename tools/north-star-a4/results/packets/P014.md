# TEST-104

## Stimulus

1. On a Linux x64 host with Git and CPython 3.11, run `git clone https://github.com/VITechnologies/projectbuddy.git pb` and then `git -C pb checkout --detach 6a9ad5cc6bf9751ea3d80467840ab6dd7e48e3f2` (member commit `6a9ad5c`). All later paths are relative to `pb`.
2. Run `python3.11 -m venv .venv` and then `.venv/bin/python -m pip install pytest==9.2.0 pyyaml==6.0.3 pillow==12.1.1 httpx==0.28.1` (the test pins of `.github/workflows/ci-assurance.yml`, without coverage tooling).
3. Run `.venv/bin/python -m pytest -v scripts/tests/test_lane_teardown.py`. Each test builds a private host layout in a pytest temporary directory with a bound run directory, a box file, and a stub `VBoxManage` (the `VBOXMANAGE_STUB` script in the test file) that reads VM states from a JSON file and logs every call; the tests drive `lane.cli.main` with `teardown` and `verify-teardown` arguments and `lane.teardown` directly. No real hypervisor is used. The file uses `fcntl` locks, so it runs on Linux only.
