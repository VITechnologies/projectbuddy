Criteria are cited by sentence number of each requirement's Fit Criterion: [[REQ-096]] C1 to C3 and [[SYS-REQ-028]] C1 to C3.

- Run total (all criteria below): step 3 exits 0 and reports `21 passed` with no failed, skipped or error result; every named node and parametrized case is reported `PASSED`.
- [[REQ-096]] C1 (the submission tool refuses to submit when its own authenticated identity is an eligible reviewer of the target environment): `test_submit_refuses_unprotected_or_self_reviewable_classes[change1-is an eligible reviewer]` lists the requester as a required reviewer and passes only when `submit` exits 3 with `is an eligible reviewer` in the `refused` output; `[change2-cannot confirm]` uses a team reviewer whose membership is unreadable and passes only when `submit` exits 3 with `cannot confirm`; `test_submit_withdraws_when_the_requester_could_approve` passes only when, after dispatch, a pending deployment reporting `current_user_can_approve` `true` makes `submit` exit 3 with `withdrawn` in `refused` and post the run's `cancel`; `test_submit_refuses_unknown_identity_drift_reuse_and_non_enforcing_classes` passes only when an unauthenticated requester (`/user` 401, no token) is refused with `identity is unknown`. `test_reviewer_eligibility_is_unknown_unless_team_membership_is_readable` passes only when `is_eligible_reviewer` returns `True` for a listed user (case-insensitive) and for a `pending` team member, `False` for a non-member of a visible team, and `None` when the team is not visible or returns 500.
