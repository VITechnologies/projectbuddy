## Stimulus

1. On a Linux x64 host with Git and Python 3.11, run `git clone https://github.com/VITechnologies/projectbuddy.git pb-test`, then `cd pb-test` and `git checkout --detach 6a9ad5cc6bf9751ea3d80467840ab6dd7e48e3f2`.
2. Create and activate a new virtual environment: `python3.11 -m venv --clear /tmp/pb-test-venv`, then `. /tmp/pb-test-venv/bin/activate`.
3. Install the pinned test dependencies: `python -m pip install --upgrade pip==26.3 pytest==9.2.0 pytest-cov==7.1.0 pyyaml==6.0.3 pillow==12.1.1 httpx==0.28.1`, then `python -m pip install --require-hashes -r tools/assisted-benchmark/requirements-synthetic-ui.txt`.
4. Run `python -m pytest -v scripts/tests/test_lane_teardown.py`. Its test cases write a stub `VBoxManage` into pytest's temporary directory and use no real hypervisor.
