# TEST-107

## Stimulus

1. On Linux x64, with Git and Python 3.11 installed, make a clean checkout of the member commit: `git clone https://github.com/VITechnologies/projectbuddy.git projectbuddy && cd projectbuddy && git checkout 6a9ad5cc6bf9751ea3d80467840ab6dd7e48e3f2`.
2. In that checkout, create a fresh virtual environment and install the CI test dependencies: `python3.11 -m venv .venv && . .venv/bin/activate && python -m pip install pytest==9.2.0 pyyaml==6.0.3 pillow==12.1.1 httpx==0.28.1`.
3. From the checkout's root, in that environment, run `python -m pytest scripts/tests/test_package_vagrant_box.py scripts/tests/test_vagrant_clone.py`. The packager cases drive `vm/ubuntu-labview/package-vagrant-box.py` against a simulated VirtualBox host and guest, and the verifier cases run `vm/ubuntu-labview/verify-vagrant-box-receipt.py` and `vm/ubuntu-labview/verify-vagrant-clone.py` on fixture receipts; no VirtualBox, Vagrant or guest runs.
