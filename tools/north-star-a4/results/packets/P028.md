# TEST-124

## Stimulus

1. On Linux x64, with Git and Python 3.11 installed, make a clean checkout of the member commit: `git clone https://github.com/VITechnologies/projectbuddy.git projectbuddy && cd projectbuddy && git checkout 6a9ad5cc6bf9751ea3d80467840ab6dd7e48e3f2`.
2. In that checkout, create a fresh virtual environment and install the CI test dependencies, including the hash-locked MCP SDK that the synthetic UI MCP server uses: `python3.11 -m venv .venv && . .venv/bin/activate && python -m pip install pytest==9.2.0 pyyaml==6.0.3 pillow==12.1.1 httpx==0.28.1 && python -m pip install --require-hashes -r tools/assisted-benchmark/requirements-synthetic-ui.txt`.
3. From the checkout's root, in that environment, run `python -m pytest scripts/tests/test_assisted_benchmark_synthetic_ui.py scripts/tests/test_assisted_benchmark_live_policy.py`. The synthetic UI cases run the offline workload fixture, oracle and MCP server in-process or on the loopback interface; no Windows VM, model or capture runs.
